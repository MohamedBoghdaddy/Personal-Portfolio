# BOGHDADDY OS Portfolio Upgrade

A Vite + React + Tailwind implementation based on the provided futuristic portfolio HTML screens.

## Install

```bash
npm install
npm run dev
```

## Routes

- `/` — Boot / Hero
- `/missions` — Mission selector
- `/flows/recruiter` — Recruiter flow
- `/flows/client` — Founder / client flow
- `/flows/technical` — Technical reviewer flow
- `/flows/fast-scan` — 60-second scan flow
- `/builds` — Boss-Level Builds
- `/skill-tree` — Skill Tree
- `/proof` — Unlocked Achievements
- `/experience` — Experience Logs
- `/terminal` — Command Terminal
- `/archive` — Early Builds Archive
- `/contact` — Launch Mission
- `/case-studies/pregen-ai-lms` — Case study template
